# Ariel Blank

I build software projects that apply algorithms to music theory and financial modeling.

## Selected projects

- [Jazz Chord Analyzer](https://github.com/ablank333/jazz-chord-analyzer) — Java tool that assigns Roman numerals to jazz chords and detects ii–V–I progressions.
- [Monte Carlo Stock Price Simulator](https://github.com/ablank333/Monte-Carlo-Stock-Price-Simulator) — Java web app that runs 10,000 simulated price paths using historical market data and visualizes the resulting distribution.
